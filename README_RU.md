# Flipbook Studio — первый технический прототип

## Что умеет
- Принимает исходное видео и отдельное настоящее видео рук/блокнота.
- Ограничивает обработку первыми 30 секундами исходника.
- Может применить карандашный эффект к кадрам.
- Накладывает кадры на заданную четырёхугольную область страницы и создаёт MP4 1920×1080.

## Важные ограничения этой первой версии
- Это технический прототип, не готовый продукт.
- Для работы нужен сервер с FFmpeg и OpenCV; открыть `index.html` как файл на iPhone недостаточно.
- Область страницы пока задаётся вручную числами, а не выбирается касанием на видео.
- Наложение использует фиксированную перспективу. Оно пока не отслеживает изгиб/движение страницы и не сохраняет реалистичную окклюзию рук поверх рисунка на протяжении всего перелистывания. Поэтому результат зависит от выбранного видео и может выглядеть неестественно.
- Прототип следует использовать с видео, на которое у вас есть права или разрешение.

## Развёртывание
Можно развернуть как Python web service на Render (или совместимом хостинге), загрузив содержимое проекта в репозиторий Git. `render.yaml` и `Procfile` включены. Для длительных обработок и больших файлов потребуется проверить лимиты выбранного хостинга и добавить фоновые задания/хранилище.
